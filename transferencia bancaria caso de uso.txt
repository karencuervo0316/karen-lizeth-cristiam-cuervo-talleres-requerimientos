Realizar transferencia bancaria


Scenario: Transferencia exitosa
  Given que el cliente está autenticado y tiene saldo suficiente
  When el cliente ingresa una cuenta destino válida y un monto válido y confirma
  Then el sistema procesa la transferencia
  And el sistema muestra el comprobante
  And se envía notificación al cliente

Scenario: Saldo insuficiente
  Given que el cliente está autenticado
  When el cliente intenta transferir un monto mayor al saldo disponib
  Then el sistema muestra "Saldo insuficiente para realizar la operación"
  And no se realiza la transferencia

Scenario: Cuenta destino inexistente
  Given que el cliente está autenticado
  When el cliente ingresa un número de cuenta destino que no existe
  Then el sistema muestra "Cuenta destino no encontrada"
  And permite corregir el dato o cancelar

Scenario: Cancelación de la operación
  Given que el sistema muestra el resumen de confirmación
  When el cliente decide cancelar
  Then el sistema descarta la operación
  And no se realizan cambios en las cuentas

Scenario: Fallo del servicio de transferencia
  Given que el cliente confirmó la operación
  When ocurre un fallo en el core bancario durante el procesamiento
  Then el sistema revierte cualquier cambio parcial (rollback)
  And el sistema muestra "No fue posible completar la transferencia. Intente más tarde"
